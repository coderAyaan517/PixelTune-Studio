# PixelTune Studio

A lightweight browser-based image editor built with HTML, CSS, and JavaScript. It allows users to upload an image, adjust visual filters in real time, apply creative presets, and download the edited result instantly.

## Features

- Upload any image from your device
- Real-time editing with controls for:
  - Brightness
  - Contrast
  - Saturation
  - Hue rotation
  - Blur
  - Grayscale
  - Sepia
  - Opacity
  - Invert
- One-click preset filters including:
  - Drama
  - Vintage
  - Noir
  - Cyberpunk
  - Warm Sunset
  - Soft Glow
- Reset adjustments to default values
- Download the final edited image as a file

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Canvas API

## How to Run

1. Open the project folder in your browser, or use a local development server.
2. Open `index.html` in a browser.
3. Click on the "Choose Image" button and upload an image.
4. Adjust the sliders or click a preset to apply effects.
5. Click "Download" to save the edited image.
